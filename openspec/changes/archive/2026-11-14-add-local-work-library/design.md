## Context

asmr.one 使用数字作品 ID，下载索引与播放进度已经存有用户数据。本地来源需要独立身份与文件管理，同时复用现有目录和播放逻辑。

## Goals / Non-Goals

统一作品导航、基础详情、轨道资源与播放恢复。asmr.one 的账户操作、推荐、搜索及下载由平台模块继续提供。首版管理导入副本，外部文件夹引用和同步留给独立需求。

## Decisions

- 使用 `WorkReference` 标识来源。保留现有在线 DTO、下载索引、缓存键及续播载荷格式。来源代理返回统一详情与目录；在线详情继续先展示缓存，再刷新及保护标记状态。
- 通过系统「文件」选择器导入单个目录，在安全作用域内协调读取并复制支持的文件。以 UUID 目录和独立清单存储每部作品，原子移动暂存目录发布，删除先移出库再清理。
- 选填 `wisimi.json` 中的 `title`、`circle`、`duration`、`rating`、`sales`、`catalogCode`、`tags`、`voiceActors` 和 `cover` 由本地来源解释。默认标题来自目录名，字幕状态由实际文件推断，封面路径须指向已导入的图片。
- 本地库与在线页共用一个播放器和导航容器。导入轨道的 ID 用作品内相对路径表示，续播从导入清单重新解析沙盒 URL。

## Risks / Trade-offs

- 大型作品产生额外存储占用。复制前提供空间预估和取消，失败只清理暂存副本。
- 文件提供方无法读取、空间不足或 App 中断时，原作品和已发布作品保持可用。
- 本地 VTT/LRC 可离线读取。开启在线旁白时仍由现有 TTS 设置和服务决定合成行为。
